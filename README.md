# IPAMD

Daemon for accessing a small IP Address Management IPAM database.  This script requires the py-libipam library.

See ipamd.md for how to use.

# Notes

The IPAMD daemon is expected to be called from the ipamctl script.  The daemon has a rudementry RBAC capability.

See [ipamd.md] for more information about running IPAMD
See [ipam.ini.md] for configuration IPAMD configruation file.
